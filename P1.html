Desktop Voice Assistant (DVA)

A command-line voice assistant built with Python to enhance productivity and automate desktop tasks on Windows.

The Desktop Voice Assistant is a powerful, command-line-based application designed to bring the convenience of hands-free control to the personal computer environment. Developed entirely in Python, this project addresses the inefficiencies of traditional keyboard and mouse interaction by allowing users to execute a wide range of commands using only their voice. It serves as a practical tool for streamlining daily workflows, enhancing accessibility, and automating repetitive tasks.

Core Capabilities


  • Information Retrieval: Execute commands like "what's the time?", "what's the weather in Bhopal?", or "search Wikipedia for Python programming language".

  • Productivity Management: Manage a to-do list with commands like "add 'finish report' to my list" or engage in a full, interactive dialogue to "send email".

  • System & Application Control: "Open Notepad", "open website YouTube", control Spotify with "play music 'Blinding Lights'", and even manage system power with "shutdown computer".

Technology Stack


  • Speech Recognition & Synthesis: SpeechRecognition captures microphone input and uses Google's Web Speech API for high-accuracy transcription, while pyttsx3 provides a clear, offline voice for responses.

  • API & Web Integration: requests is used for making calls to external weather and news APIs, wikipedia for summarizing articles, and spotipy for controlling Spotify playback.

  • System Automation: Windows-specific libraries like pycaw and comtypes are used to manage system volume and power states, and pyautogui is used for taking screenshots.

Development Challenges & Solutions


  • Challenge: Designing the logic for multi-step, interactive commands like sending an email proved to be complex within the main application loop.

  • Solution: The entire interactive flow was encapsulated within its own function (e.g., send_email()), making the command logic self-contained and dramatically simplifying the main loop.

  • Challenge: Improving the recognition of short words like "yes" and "no" during these interactions was difficult.

  • Solution: This was resolved by implementing the adjust_for_ambient_noise() function from the SpeechRecognition library, which calibrates the microphone to the user's environment for better accuracy.
