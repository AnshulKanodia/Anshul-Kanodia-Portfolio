**Anshul Kanodia - Personal Developer Portfolio**

Welcome to the source code for my personal developer portfolio. This project is a showcase of my skills, projects, and professional background, presented with a clean, futuristic, and animated design.

**Live Site:** anshulkan.vercel.app


**About This Project**

This portfolio was built from scratch to serve as a central hub for my professional identity. It details my journey as a Computer Science undergraduate, my passion for AI and System Development, and the work I'm most proud of.


**Features**

**Futuristic UI:** A modern, dark-themed design with electric blue accents and animated, glowing elements.

**Dynamic Animations:** Features a rotating hero border, subtle hover effects, and a live particle background for a high-tech feel.

**Fully Responsive:** The layout is optimized for a seamless experience on all devices, from mobile phones to desktop monitors.

**Multi-Page Layout:** Includes a detailed, separate page for an in-depth look at key projects.

**Functional Contact Form:** Integrated with Formspree to handle form submissions securely and efficiently.


**Technology Stack**

This website was built using foundational web technologies:

**HTML5:** For the core structure and content.

**CSS3:** For custom styling, animations, and the overall futuristic theme.

**Tailwind CSS:** For a utility-first approach to responsive design and layout.

**JavaScript:** For interactive elements like the particle background, mobile menu, and AJAX contact form submission.


**How to View**

To view the project locally, simply clone the repository and open the index.html file in your web browser.
