Desktop Voice Assistant (DVA)

A command-line voice assistant built with Python to enhance productivity and automate desktop tasks on Windows.

Project Overview

The Desktop Voice Assistant is a lightweight, terminal-based application designed to bring hands-free convenience to the local computer environment. Developed entirely in Python, this utility addresses the friction of traditional keyboard/mouse commands by interpreting natural speech commands to drive core operating system tasks. It streamlines workflows, supports accessibility requirements, and automates mundane operations.

Core Capabilities

  • Information Retrieval: Executes voice commands to retrieve system statistics, local time, regional weather forecasts, or parse Google/Wikipedia indexes instantly.
  • Productivity Management: Manages local to-do logs and orchestrates interactive flows to capture details and send emails directly via user commands.
  • System & App Control: Launches applications (e.g. Notepad, browser windows), interfaces with Spotify to coordinate music selection, controls system volume levels, and manages computer power states.

Technology Stack

Python SpeechRecognition Library pyttsx3 Offline TTS Windows Volume APIs (pycaw / comtypes) Spotipy API

Challenges & Solutions

Multi-Step Interactive Workflows

Standard loop layouts make handling stateful commands (such as formatting and sending an email in parts) very confusing, leading to thread blocks or inputs getting lost.

Solution: Encapsulated individual multi-step operations in self-contained routines (e.g. send_email() function). This decoupled interactive states from the main loop and simplified maintenance.

Ambient Noise Interference

Short spoken words like "yes" or "no" are easily lost in noisy rooms, leading to command errors and misinterpretations.

Solution: Configured adjust_for_ambient_noise() during initializations. This dynamically calibrates microphone gain thresholds to the surroundings, raising phrase recognition accuracy.
