RupeePulse

Sovereign Personal Finance & Khaata Ecosystem engineered with Next.js 14, Progressive Web App & Android TWA, Dynamic NPCI UPI QR Settlements, and Zero-Telemetry Privacy.

Project Overview

RupeePulse is a modern, privacy-first personal financial management ecosystem built specifically for the Indian financial ecosystem. Unlike conventional fintech applications that monetize user telemetry or break during intermittent connectivity, RupeePulse operates on an offline-first architecture powered by Next.js 14 App Router, client-side IndexedDB, and an Android Trusted Web Activity (TWA) container with cryptographic Digital Asset Links.

It unifies two traditionally disconnected paradigms: sovereign personal expense management (with dynamic budget runway pacing and daily burn-rate badges) and bilateral peer-to-peer Khaata credit ledgers (complete with on-the-fly NPCI UPI QR code generation and 1-tap WhatsApp statement broadcasting).

Core Architectural Capabilities

  • Vault Guard Budget Pacing Engine: Dynamically calculates daily burn-rate runway, unallocated spending headroom, and real-time transaction interceptor with visual alert badges (Green: Safe, Amber: Caution, Rose: Breached).
  • Khaata Split Ledger 2.0: Continuous bilateral passbooks supporting partial settlements, directional debt graphs, 1-tap WhatsApp statement sharing with full UTF-8 emoji preservation, and real-time NPCI UPI QR code generation.
  • Quick Add 2.0 with Merchant Category Predictor: Speed dial interface optimized for single-thumb mobile usage with zero typing latency, auto-suggesting categories based on historical transactions.
  • Offline Resilience & FIFO Background Sync: Uses IndexedDB to persist inputs instantaneously when offline, rolling back optimistic UI states gracefully if network collisions occur.
  • Sovereign Backup & Restore: Generates self-contained JSON data snapshots and provides an interactive modal with schema validation for granular merge or overwrite restoration.
  • Multi-Layer Biometric Security: Protects financial data using WebAuthn biometric passkeys, a PBKDF2/SHA-256 encrypted 6-digit PIN vault, session-locked JWT cookies, and an instant stealth privacy filter.

Engineering Challenges & Solutions

Android TWA Address Bar Leakage

Installing as a native APK initially forced Chrome to display an ugly browser URL bar at the top of the app due to Android's strict origin verification protocol.

Solution: Extracted the exact APK signing certificate SHA-256 fingerprint, configured a compliant Digital Asset Links manifest at /.well-known/assetlinks.json, and bypassed authentication middleware for Google's verification bot.

NPCI Dynamic UPI QR Formatting

UPI deeplinks often break or reject partial settlement amounts across banking apps (GPay, PhonePe, Paytm) when URL parameters have non-standard encoding or missing currency symbols.

Solution: Formulated a standard NPCI specification compliant string builder (upi://pay?pa=...&pn=...&am=...&cu=INR) rendered via high-contrast client SVG with error correction Level M.

Zero-Lag Financial Calculations

Re-evaluating dynamic monthly burn rates, headroom allocations, category totals, and multi-currency exchange rates on every keystroke in Quick Add introduced frame-drops on low-power devices.

Solution: Decoupled heavy quantitative models into memoized Web Workers and Pure TypeScript calculation engines, backed by 64 unit tests running in under 200 milliseconds.

Offline Queue State Drift

Transactions submitted while offline could conflict with changes made from another device or fail if network connection is restored midway during a batch sync.

Solution: Implemented an idempotent FIFO synchronization worker utilizing IndexedDB object stores with exponential backoff retry and optimistic UI rollback.
